# Introduction to HTML – Course Page

Single-page course site built with HTML only (no CSS or JavaScript).

## Publish
1. `git init`
2. `git add .`
3. `git commit -m "Initial course page"`
4. `git branch -M main`
5. `git remote add origin https://github.com/<username>/<repo>.git`
6. `git push -u origin main`
7. On GitHub: **Settings → Pages → Deploy from branch → main / (root)**.

Site URL: `https://<username>.github.io/<repo>/`
