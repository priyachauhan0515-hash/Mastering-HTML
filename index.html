Overview

This unit introduces the structure of web pages. You will learn semantic elements, lists, text formatting, media embedding and publishing with GitHub Pages.

Learning Outcomes

  1. Write a valid HTML5 boilerplate.
  2. Organise content with semantic elements.
  3. Embed images, audio, video and iframes.
  4. Version and publish a site using Git and GitHub.

Core Concepts

Semantic Elements

  • Page landmarks
    • <header> and <footer>
    • <nav> and <main>
    • <aside>
  • Content grouping: <section>, <article>, <figure>

Key Terms

Element
A start tag, content and an end tag.
Attribute
Extra information inside a start tag, e.g. href.
Entity
A code such as &lt; that displays a reserved character.
