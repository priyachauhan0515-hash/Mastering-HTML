Course Overview

Web Technology introduces students to the basic concepts of designing and developing websites.

Students will learn how to create web pages using HTML and understand the basic structure of a website.

Learning Objectives

  • Understand the structure of an HTML document.
  • Create semantic web pages.
  • Use headings, paragraphs, lists and links.
  • Add images, audio and video.
  • Publish a project using GitHub Pages.

Course Topics

1. Introduction to Web Technology

Web technology includes the tools and technologies used to create and access websites and web applications.

2. HTML

HTML stands for HTML. It provides the basic structure of a webpage.

Steps to Create a Web Page

  1. Open a text editor such as VS Code.
  2. Create an HTML file.
  3. Write the HTML structure.
  4. Add content and links.
  5. Save the file as index.html.
  6. Open it in a web browser.

Git & GitHub

Git is a version control system used to track changes in a project. GitHub provides an online platform for storing and sharing Git repositories.

Basic Git Workflow

  1. Initialize the repository.
  2. Add project files.
  3. Commit the changes.
  4. Push the project to GitHub.

Example Git commands: 

git init
git add .
git commit -m "Initial course page"
git branch -M main
git remote add origin YOUR_GITHUB_URL
git push -u origin main
